# 问题四直接移动控制体验证：离散原理与验证边界

## 任务范围与现有实现核对

本轮只新增问题四的坐标实现互证，不改原主模型、原始终算数据或 result4.xlsx。参考路径调用原 advance_coupled，独立维护自己的状态；新路径只复用初始参数、PCHIP 边界读取、节点分布及附件四物性，另外组装物理控制体矩阵。每步的温度和水分均从各自前一时间层推进，不相互注入状态。

现有 simulate_moving 默认 include_advection=False，其含义是材料与网格同速的均匀径向收缩，而不是忘记移动通量。传给 advance_coupled 的半径导数被置零，是为了消除相对材料速度项，半径本身仍按真实 R(t) 更新。此实现写法不直观，但与论文现有的 v_s=w、干骨架质量守恒假设一致。本轮不修改该主程序。

## 一、物理环形控制体

节点 r_i(t)=R(t) ξ_i，ξ_i=1-(1-i/160)^2。ξ_i 仅作节点轨迹标签，新求解器不在 ξ 坐标上写微分算子。每步在物理 r 坐标重新构造界面 b_0=0、b_N=R 和内部中点 b_{i+1/2}=(r_i+r_{i+1})/2。

按单位轴长，体积 V_i=π(b_{i+1/2}²-b_{i-1/2}²)，界面面积 A_f=2π b_f。导通系数直接由 A_f、相邻节点物理距离及界面物性构成，不使用 R^(-2) 或 R^(-1) 变换系数。

时间步内用端点位移定义界面平均速度 w_f=(b_f^{n+1}-b_f^n)/Δt，平均扫掠面积 Abar_f=π(b_f^{n+1}+b_f^n)，于是精确满足离散几何守恒：

V_i^{n+1}-V_i^n = Δt [(Abar w)_{i+1/2}-(Abar w)_{i-1/2}]。

这相当于在每个离散时间段内使用端点一致的分段线性面轨迹；物理半径端点仍由 PCHIP 给出。不用末时刻面积乘末时刻 PCHIP 导数去替代有限时间段的扫掠体积，避免几何守恒误差。

## 二、干基水分的移动控制体守恒

一般 ALE 水分平衡为 d∫ρ_d C dV/dt + ∮[ρ_d C(v_s-w)+j_w]·n dA=0，j_w=-ρ_d D∇C。均匀径向材料收缩使 v_s=w，因此相对对流通量严格为零；干骨架连续性给出每个材料控制体的干质量不变。

令 M_d 为总干质量（按单位轴长），ρ_d^n=M_d/ΣV_i^n，m_i^n=ρ_d^n V_i^n。本程序取初始 ρ_d=1 作为归一化基准；该任意正常数同时乘储存与水分通量，完全约掉，不是新增拟合物性参数，也没有用题给湿密度去反演它。

每步采用全隐式库存式：

(m_i^{n+1} C_i^{n+1}-m_i^n C_i^n)/Δt
= Σ_{j相邻} G_ij^{n+1}(C_j^{n+1}-C_i^{n+1})
- δ_{i,N} ρ_d^{n+1} A_s^{n+1} h_m(C_s^{n+1}-C_e^{n+1})，

其中 G_ij=ρ_d A_f D_f/|r_j-r_i|，D_f 为两侧节点物性的算术平均，与主模型的界面物性口径相同。内通量成对抵消，全域水质量变化等于外边界损失。节点位置变化不会凭空产生水，也不会把体积收缩误解为干基浓度增大。

错误形式 (V_new C_new - V_old C_old)/Δt=扩散通量 把 C 当作单位现体积水质量，忽略干基定义与骨架连续性。即使完全绝热绝湿，它也会导致 C 因收缩而增加，不是本题现有模型的物理对应形式。

## 三、温度方程的准确口径

现有热方程是 a D_t T=div(k∇T)，a=ρ(C)c_p(C)。a 不一定满足材料密度连续性，所以不能把该方程无条件改写为无源的 d∫aT dV/dt=边界热流。

对于随材料运动的控制体，它的库存表示为 d∫aT dV/dt=∮k∇T·n dA+∫T(D_t a+a div v_s)dV。离散令 H_i=a_i V_i，则采用

H_i^{n+1}T_i^{n+1}-H_i^nT_i^n
= Δt Σ热通量 + T_i^n(H_i^{n+1}-H_i^n)。

右侧末项是原有效热方程在变体积、变储热系数库存变量下必需的离散修正，代数上等价于 H_i^{n+1}(T_i^{n+1}-T_i^n)=ΔtΣ热通量；不是为拟合结果新增的外热源。两式均一阶时间一致。新程序显式构造并核验该修正，不能宣称 aVT 无源守恒。完整热力学能量模型还需一致的比焓、骨架密度与含水关系、汽化潜热及相应通量，现有数据与主模型未提供这套闭合。

## 四、理论判断

在原论文均匀材料收缩、干基浓度、有效热方程假设下，没有发现水分守恒形式与固定域主模型矛盾。物理控制体库存式除以均匀干密度、再用 r=Rξ 表达，可代数回到主模型的离散系统；因此两种实现可能只差浮点舍入，但差值必须由实际运行给出。

这种“独立”指几何构造与矩阵组装的独立实现，采用相同网格、物性、线性求解器和时间离散，不是第二套独立物理定律，也不是实验验证。吻合支持结果不依赖单一坐标表达/实现，不能证明均匀收缩、无潜热或径向降维假设对真实药材必然成立。

## 外部方法核对

移动控制体需兼顾时空守恒与 GCL，这一方法原则可参考 Gaburro, Dumbser, Castro 的直接 ALE 论文：https://arxiv.org/abs/1602.01703 。本文未照搬其非结构高阶格式，而是为本题一维材料环形控制体独立推导上述一阶离散；实际正确性另以本地守恒测试和重算对比核验。

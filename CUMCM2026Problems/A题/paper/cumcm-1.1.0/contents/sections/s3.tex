\section{模型假设}

为使题目给出的数据能够封闭控制方程，并保证四问口径一致，作如下假设。

\begin{enumerate}
  \item \textbf{连续介质与轴对称假设。}药材内部视为均匀、各向同性的连续多孔介质，初始温度和水分浓度均匀，烘房条件关于圆柱轴线对称，故不存在周向梯度。该假设使三维问题可先化为轴对称问题。
  \item \textbf{中截面径向主导假设。}圆柱长径比为 6.25，题目只要求径向位置的输出，因此主模型描述远离端面的中截面径向场，暂不计轴向通量。端面影响不被直接忽略，而是在模型检验中用二维轴对称计算量化其适用范围。
  \item \textbf{扩散主导假设。}药材内部热量由导热传递，水分由等效 Fick 扩散传递；忽略内部体热源、辐射、孔隙内宏观自然对流、重力渗流以及药材与托盘的接触传热。题目给出的等效物性被认为已经综合微观孔隙结构的平均影响。
  \item \textbf{表面交换假设。}圆柱侧表面与环境通过对流换热和对流传质交换，系数分别取 $h_T=25~\mathrm{W/(m^2K)}$ 与 $h_m=8\times10^{-7}~\mathrm{m/s}$。附件三、四未给出新的表面系数，因此问题二至四沿用附件二数值，保证比较只由物性和几何变化引起。
  \item \textbf{热湿耦合口径。}温度方程不额外加入汽化潜热项。题面未给出蒸发潜热、平衡吸湿曲线、相变界面和交叉输运系数，强行加入会产生无法由现有数据辨识的参数。本文以 $\rho(C),c_p(C),k(C)$ 和 $D(T,C)$ 表达题目明确给出的状态耦合，并在模型评价中说明该简化的影响。
  \item \textbf{环境延拓假设。}附件一覆盖 $0\sim14400$~s。问题三、四超过该时段后，环境温度和水分浓度分别保持附件末值 $50.165~{}^\circ\mathrm C$ 和 $0.04986~\mathrm{kg/kg}$，表示烘房进入稳定运行阶段；并通过 $\pm5\%$ 扰动检验该延拓对达标时间的影响。
  \item \textbf{均匀径向收缩假设。}问题四中长度保持 25~cm，各材料点随半径同比例收缩，因而可用 $\xi=r/R(t)$ 标记材料坐标。干骨架质量守恒且其现体积密度在截面内均匀，满足 $\rho_d(t)R(t)^2=\rho_d(0)R_0^2$；题给 $\rho c_p$ 用作有效储热系数，不另以它反演干骨架密度。附件二半径经单调 PCHIP 重构，不允许插值后出现局部回弹或超出数据范围。
  \item \textbf{浓度量纲一致假设。}题目中的药材水分浓度和环境水分浓度均按 kg/kg 的同一干基比值处理，扩散方程与表面传质边界直接采用该量。若实际环境量为相对湿度，则需先通过吸湿等温线换算，本文不进行无数据支持的转换。
\end{enumerate}

上述假设将未知的内部传热传质归结为可由题给物性和环境数据驱动的初边值问题。其中第 2、5、6 项对长期结果最敏感，故分别安排二维核验、模型局限讨论和边界灵敏度分析，而不是将其视为无需检验的先验事实。

\section{模型的检验、评价与推广}

\subsection{时间步长收敛检验}

问题三、四的最终答案由阈值事件决定，对时间离散误差较为敏感。为避免仅凭全隐式格式的稳定性代替精度检验，将基准步长 10~s 减半为 5~s，并保持相同空间网格、边界插值和事件定位方法。结果见\cref{tab:verify}：问题三达标时间从 56.1863~h 变为 56.1820~h，绝对差 15.61~s；问题四从 51.9857~h 变为 51.9826~h，绝对差 11.12~s。两者相对差均小于 $8\times10^{-5}$，远小于题目每 60~s 输出一次的时间尺度。

需要指出，全隐式格式允许较大时间步只说明计算不会因扩散稳定性条件而发散，并不意味着大步长下首达时刻准确。本文采用“基准步长—减半步长—连续事件插值”的三级处理，使稳定性、离散精度和阈值定位分别得到控制。问题三、四在减半步长下结论和控制位置均未改变。

\subsection{二维轴对称独立核验}

为检验忽略端面的影响，另建立半圆柱域
\[
0\le r\le R_0,\qquad 0\le z\le L/2
\]
上的二维轴对称有限体积模型。利用关于中截面 $z=L/2$ 的对称性只计算半长区域，在 $r=R_0$ 和 $z=0$ 同时施加与一维模型一致的热、质 Robin 边界，在 $r=0$ 与 $z=L/2$ 施加零通量条件。二维网格包含 21 个径向节点和 26 个半轴向节点，时间步长取 10~s。

二维中截面与一维模型采用相同初值、侧表面边界和物性，因此二者的差异可直接反映端部扰动是否传播到中截面。在 0--1800~s 核验时段内，中截面最大温差仅 $2.42\times10^{-7}~{}^\circ\mathrm C$，最大水分差为 $8.17\times10^{-13}~\mathrm{kg/kg}$，说明对于本题长径比和短期场，一维径向模型能够高精度表示中截面。

另一方面，二维端面与中截面的最大温差达到 $3.6576~{}^\circ\mathrm C$。
相应的最大水分差达到 $0.8567~\mathrm{kg/kg}$。这并不否定一维解，而是限定其解释范围：本文表格和图形描述的是圆柱中部径向分布，不能直接作为端面附近的局部预测。若题目要求整根药材的全体积最大水分或药材长度明显缩短，应使用二维模型直接判定全域阈值。

环境温度降低 5\% 时，问题三、四时长分别增加 8.32\% 和 8.19\%；温度升高 5\% 时，分别减少 7.41\% 和 7.32\%。相比之下，环境水分的 $\pm5\%$ 扰动只引起约 $0.18\%\sim0.26\%$ 的时长变化。以对称差分定义无量纲灵敏度
\begin{equation}
S_x=\frac{t_d(x+5\%)-t_d(x-5\%)}{0.10t_d(x)},
\label{eq:sensitivity}
\end{equation}
得到温度灵敏度在问题三、四中分别约为 $-1.57$ 和 $-1.55$，环境水分灵敏度约为 0.048 和 0.039。负温度灵敏度表示提高温度会缩短干燥时间，正水分灵敏度表示更湿的环境会延长干燥时间。

温度灵敏度绝对值远大于环境水分灵敏度，根本原因是 $D(T,C)$ 含 Arrhenius 温度指数，而本题后期材料表面水分已接近环境水平、内部过程主要受有效扩散率控制。问题三、四对扰动给出相同的方向和相近的无量纲幅度，也说明收缩模型没有改变环境因素作用的基本物理方向。

\subsection{模型优点}

本文模型具有以下特点：
\begin{enumerate}
  \item \textbf{统一性。}四问均由同一 Fourier--Fick 控制方程和有限体积离散出发，新增物性、阈值与收缩时只扩展相应模块，避免结果口径分裂。
  \item \textbf{守恒性。}有限体积法直接对环形控制体平衡通量，中心奇点和表面 Robin 边界都有明确几何意义；三对角矩阵结构也便于检查系数符号和对角占优。
  \item \textbf{可解释性。}特征时间解释问题一的热快湿慢，状态物性解释问题二的干层阻力，首达事件解释问题三的中心控制，反事实模型则把问题四的几何作用与物性差异分开。
  \item \textbf{可复现性。}环境和半径均采用确定性的 PCHIP，数值程序无随机过程；逐时空工作簿、论文表格与数据图来自同一终算文件，并通过步长、二维和文件回读多重检查。
  \item \textbf{输出完整性。}固定域解与固定物理位置输出被明确区分，落到收缩药材外部的列按几何规则留空，真实首达时间也不被 60~s 输出间隔量化。
\end{enumerate}

\subsection{模型局限}

首先，热湿耦合只通过题给物性函数体现，没有显式描述水分蒸发消耗的潜热。若真实蒸发冷却显著，本文可能高估材料升温速度并进一步高估 $D(T,C)$。但在缺少潜热、平衡吸湿关系和相变边界数据时，加入该项需要额外参数，不能由现有附件唯一确定。

其次，主模型代表中截面而非端面。二维核验已经量化短期端部差异，若最终质量标准要求整根药材任何三维位置都达标，则中心轴线与轴向中截面的组合是否仍为控制点应由二维长期计算重新判断。再次，材料被视为均匀各向同性；实际药材的纤维方向、表皮和内部空腔可能使径向与轴向扩散系数不同。

最后，4~h 后环境采用常值延拓，虽然灵敏度分析表明结论对小幅扰动稳定，但它仍是长期预测的主要外部不确定性来源。问题四又假设收缩为均匀径向缩放，没有考虑局部开裂、翘曲和长度变化。本文结果因此更适合作为给定附件条件下的理论预测和控制基线，而非未经标定即可替代实际烘干试验。

\subsection{工程应用与模型推广}

从控制角度看，表面温度和表面水分都过早接近环境或阈值，不能单独作为停机信号。可在少量试验中布置中心温湿传感器，用本文模型反演或校正 $D,h_m$，随后建立由环境历史和表面观测预测中心水分的降阶代理模型。控制器以预测中心水分首次达到 0.15 为停机条件，可兼顾内部达标与表层不过度干燥。

根据问题一至三的阶段特征，还可构造两阶段温度策略：早期在允许的品质温度范围内提高环境温度，利用较高 $D$ 加快内部扩散；后期中心接近阈值时降低温度或采用间歇均湿，使内外水分重新分配。具体最优温度轨迹需要增加品质损失、能耗和设备上下限等目标与约束，本文框架可直接作为最优控制中的状态方程。

若获得蒸发潜热、平衡含湿曲线和交叉输运系数，可将\cref{eq:heat,eq:mass}推广为 Luikov 型热湿耦合方程\cite{luikov1975}；若药材长度较短或端面换热强化，则采用本文二维核验模型；若收缩出现各向异性，则把单一 $R(t)$ 扩展为轴向、径向两个尺度函数。因而，该方法不仅适用于中药材，也可用于果蔬、食品、木材及其他多孔生物材料的变物性干燥和收缩预测。

        变物性与收缩边界下圆柱药材的热湿迁移建模
                            摘要
   针对圆柱形药材烘干中环境边界时变、内部温湿分布不均、物性非线性及几何收缩
相互影响的问题，本文构建统一的变物性径向热湿有限体积框架。以 PCHIP 重构附件
中的环境量和半径曲线，以 Fourier–Fick 方程描述内部传递，采用节点中心有限体积法
与全隐式格式保证离散守恒和长时计算稳定，并通过 Picard 迭代处理状态相关物性；进
一步以材料坐标下的固定域映射描述收缩边界，以全截面首达时间统一衡量干燥终点。
   针对问题一：在固定半径和给定物性下，建立常物性 Fourier–Fick 基准模型，将时变
环境量作为双 Robin 边界输入并逐秒求解。1800 s 时中心与表面温度分别为 33.577 ◦ C
和 36.786 ◦ C，水分浓度分别为 2.550 和 1.510 kg/kg。结果表明预热初期水分主要从
表层逸出，内部仍接近初始状态。
   针对问题二：在基准模型上引入 ρ(C), cp (C), k(C) 与 D(T, C)，构造温度–水分状态
耦合的非线性扩散模型，每个时间层交替更新温度、扩散系数和水分场。3 h 时中心与
表面温度达到 49.849 ◦ C 和 49.967 ◦ C，水分浓度降至 1.766 和 1.008 kg/kg。此时径
向温差已很小，而水分梯度仍然明显，后续过程主要受内部传质控制。
   针对问题三：将问题二模型延伸至长期干燥，以 maxr C(r, t) ≤ 0.15 kg/kg 定义全
截面达标，并对跨越阈值的相邻时间层实施线性事件插值。4 h 后按恒温工艺设定取
Te = 50 ◦ C、Ce = 0.05 kg/kg。全域首达检测得到干燥时间为 57.472 h，达标瞬间中心
和表面水分浓度分别为 0.150 和 0.053 kg/kg。全程中心均为最大值，说明仅依据表面
含水率停机将低估内部干燥时间。
   针对问题四：令 ξ = r/R(t)，补充均匀材料收缩及干骨架守恒假设，使材料速度与
网格速度相同，在固定域中求解相对输运为零的扩散方程；同时设置附件四物性下的固
定半径反事实模型以隔离几何效应。移动边界模型得到干燥时间为 51.088 h，达标半径
为 1.200 cm；同物性固定半径方案需 129.845 h，收缩使时长缩短 60.7%。其主导机
制是径向扩散距离持续减小。进一步采用移动网格验证在物理坐标中独立组装控制体，
所得达标时间和场量差异处于浮点舍入量级；采用 COMSOL 有限元复核检查径向场分
布。两种独立实现共同验证了主模型在既定假设下的数值准确性；有限元复核的具体偏
差及近表层网格限制见正文。
   采用 161 个表面加密节点和 1 s 步长终算。节点加密至 321 个及步长由 2 s 减为 1 s
时，问题三、四达标时间的相对变化均小于 2 × 10−5 ；长期二维核验进一步检查全域控
制位置，离散质量与有效热方程平衡残差均接近舍入误差水平。灵敏度采用一致步长和
明确的温度增量定义，结果表明环境温度是主要外部控制量。模型结论依赖给定边界与
材料收缩假设，可作为多孔生物材料干燥预测的基线。

                    一、 问题重述

1 . 1 问题背景

   药材烘干的目标并非简单地使表面水分降低，而是在不过度加热和不过度干燥表层
的前提下，使药材内部所有位置均达到规定含水标准。烘房温度升高后，热量由外向内
传递，表层水分同时在内部浓度梯度和表面对流传质的共同作用下向外迁移。由于传热
和传质的特征时间不同，药材内部会长期存在“表面已干、中心仍湿”的空间不均匀现
象。因此，只记录环境状态或表面状态不能直接判断整根药材是否完成烘干，必须建立
能够描述内部时空分布的非稳态模型。
   题目研究对象为长度 25 cm、初始半径 2 cm 的圆柱形药材，其初始温度为 28 ◦ C，
初始水分浓度为 2.55 kg/kg。附件一给出前 4 h 烘房温度和水分浓度的离散测量值，附
件二给出 72 h 内药材半径的变化记录。四个问题依次加入状态相关物性、全截面达标
约束和几何收缩效应，实质上构成由固定区域线性问题向移动区域非线性问题逐层推进
的建模任务。


1 . 2 问题提出

   根据所给几何、初始条件、环境序列和物性关系，需要获得药材温度、水分浓度随
时间及径向位置的分布，并确定内部最难干燥位置首次满足品质阈值的时刻。为使四问
结果具有统一口径，还需要明确环境数据的插值方式、表面传递边界、空间离散方法、
终止事件以及收缩后“固定物理位置”的有效范围。
   问题一：在半径和主要热物性保持不变的基准情形下，处理时变环境与药材表面的
热、质交换，计算预热阶段 0–1800 s 内的径向温度和水分浓度，并形成每 1 s、每 0.1 cm
的完整结果。该问用于建立后续各问共享的控制方程、边界条件和数值离散框架。
   问题二：在问题一基础上，将密度、比热容、导热系数及水分扩散系数改写为温度
和水分浓度的函数。模型由常系数扩散方程转为状态耦合的非线性方程，需要求得完整
烘干过程的温湿场，正文展示前 3 h 的代表结果，并分析物性变化如何影响中心与表面
的响应差异。
   问题三：沿用问题二的变物性模型，将计算时域延长至药材内部所有位置的水分浓
度均不超过 0.15 kg/kg。该问的关键不是某个离散输出时刻是否达标，而是确定全空间
最大水分浓度首次跨越阈值的连续时间，并给出每 60 s 的完整结果与每 6 h 的典型剖面。
   问题四：进一步考虑药材半径随时间收缩，并使用附件四给出的另一组状态相关物
性。计算域随时间变化，固定半径采样点还可能在后期落到药材外部。因此，需要建立

2 . 1 问题一的分析

   问题一的物性和半径在计算时段内固定，因而温度方程是线性非稳态导热方程，水
分方程仅因 D(C) 保留弱非线性。环境温度和环境水分浓度每 60 s 给出一次，而结果要
求每 1 s 输出，首先要在不引入振荡的前提下重构连续边界函数。若将药材近似为整体
均匀温度和均匀含水率，会丢失题目明确要求的径向分布，也无法解释中心与表面响应
的时间滞后。因此应采用圆柱坐标下的一维径向偏微分方程，并在轴线施加对称边界，
在表面施加对流型 Robin 边界。
   问题一同时承担数值基准的作用。其计算采用表面加密网格，再插值到题目要求的
0, 0.1, . . . , 2.0 cm 输出位置；时间步取 1 s，与提交表时间分辨率一致。通过检查温度随
半径递增、水分随半径递减、场量不越过环境和初值边界，可在进入变物性计算前确认
边界符号及圆柱控制体面积处理正确。


2 . 2 问题二的分析

   问题二给出的 ρ(C), cp (C), k(C) 和 D(T, C) 使当前时间层的系数依赖未知温湿场。
直接把旧时间层物性显式代入虽然计算简单，却会在长时间计算中引入明显的时间滞


                                         3
后；完全联立 Newton 法则需要构造较复杂的块 Jacobian。考虑到两个方程的耦合主要
通过物性传递，本文采用分步 Picard 迭代：先由当前迭代的水分更新热物性并求温度，
再用新温度与当前水分更新扩散系数并求水分，直至两个场同时收敛。
   此问还需要区分“温度接近环境”与“烘干完成”两个概念。热扩散率通常远大于
有效水分扩散率，因此 3 h 时径向温差可能已经很小，而内部含水率仍高。分析时不仅
报告各测点数值，还需比较中心—表面差及物性随干燥过程的变化，以说明后续时间为
何由传质而非传热控制。


2 . 3 问题三的分析

  “任意位置均不超过阈值”可写成空间最大值约束。由于表面直接与低水分环境交
换，径向水分场预期保持中心高、表面低，但这一判断仍需由逐时间层的数值单调性检
查确认。一旦中心被验证为全程最大点，原来的全空间终止条件便可转化为中心浓度的
一维首达事件，从而可靠确定干燥结束时刻。
   时间积分步长为 1 s，而提交结果每 60 s 输出，真实阈值时刻一般不落在任一输出
点上。若直接取第一个达标输出时刻，会带来最多 60 s 的人为偏差。因此，应保存跨越
阈值前后的两个内部时间层，依据控制浓度作线性事件插值，同时插值得到达标瞬间的
完整剖面。随后再独立生成逐分钟结果表，使“物理首达精度”和“文件输出间隔”互
不混淆。


2 . 4 问题四的分析

   问题四的困难在于计算区域 0 ≤ r ≤ R(t) 随时间收缩。若每一步在物理坐标上重新
剖分网格，就必须进行场量重映射，容易造成额外的数值扩散和守恒误差。令 ξ = r/R(t)
可把移动区域映射到固定区间 [0, 1]，材料速度与网格速度之差决定相对输运；在均匀材
料收缩假设下两者相同，相对输运为零，而扩散系数前出现 R−2 尺度因子、表面 Robin
项出现 R−1 因子。

  收缩模型的结果不能直接与问题三比较来判断“收缩贡献”，因为两问采用的物性

                         三、 模型假设

  根据题给条件，作如下假设：
1. 介质与几何。药材为均匀、各向同性的连续介质，初始温湿场均匀且轴对称；主模
 型仅考虑中截面径向传递，端面影响另用二维模型检验。
2. 传递机制。热量与水分分别由导热和 Fick 扩散传递，耦合仅通过题给状态相关物性
 体现；忽略内热源、辐射、内部宏观对流、重力渗流、托盘接触传热及汽化潜热。
3. 表面交换。表面采用对流换热、传质边界，四问均取 hT = 25 W/(m2 K)、hm =
 8 × 10−7 m/s。
4. 环境延拓。附件一覆盖的 14400 s 后进入题设恒温工艺阶段，环境温度和水分浓度取
 控制设定值 50.000 ◦ C、0.05000 kg/kg。
5. 收缩闭合。问题四长度不变，材料点沿径向同比例收缩；干骨架质量守恒且密度在
 截面内均匀，满足 ρd R2 = ρd0 R02 。题给 ρcp 仅作有效储热系数。
6. 浓度口径。药材与环境水分浓度均按同一干基比值处理，直接用于扩散方程及表面
 传质边界。

6 . 2 离散方案与求解步骤

   取 N = 160，采用表面加密的 161 个计算节点，再线性插值到 0, 0.1, . . . , 2.0 cm 的

方程中的 D(C) 仍随局部含水率变化，故与温度场一起按 Picard 框架求解。

得 T n+1 ；随后依据当前水分迭代值更新各节点及界面的 D，求得 C n+1 ；最后进行收敛、
范围和单调性检查。问题一每个时间层最多 4 次 Picard 迭代即可达到给定容差。由于温
度方程在本问中为线性，额外迭代主要用于水分扩散系数的自洽更新。
   在物理边界上，中心节点不设置虚拟负半径点，而直接使用中心圆盘控制体和零内
侧通量；表面节点使用半环形控制体，并将 2πR0 hT 或 2πR0 hm 加入矩阵末行。这种处
理同时保持圆柱几何和局部通量守恒，避免简单中心差分在 r = 0 处分母为零的问题。

7 . 1 非线性模型及耦合关系

                                           H[T ; C] = 0,         M[C; T ] = 0,                   (20)

其中两个算子通过状态相关系数双向联系。该耦合不要求在一个大矩阵中同时求解全部

纲温度弹性，应以绝对温度定义 ST = (Te,K /td )KT ，两问分别为 −10.2874、−10.1504，
而不是将摄氏数值直接作百分比归一化。
   温度升高缩短干燥时间，环境水分升高延长干燥时间。在本组扰动幅度下，温度影
响明显大于环境水分；这一方向与 D(T, C) 中 Arrhenius 温度因子一致。该比较针对给
定扰动、延拓时段和固定半径历史，不是包含几何反馈的总灵敏度。


10 . 4 模型优点

   本文模型具有以下特点：
1. 统一性。四问均由同一 Fourier–Fick 控制方程和有限体积离散出发，新增物性、阈值
  与收缩时只扩展相应模块，避免结果口径分裂。
2. 守恒性。有限体积法直接对环形控制体平衡通量，中心奇点和表面 Robin 边界都有
  明确几何意义；三对角矩阵结构也便于检查系数符号和对角占优。
3. 可解释性。特征时间解释问题一的热快湿慢，状态物性解释问题二的干层阻力，首
  达事件解释问题三的中心控制，反事实模型则把问题四的几何作用与物性差异分开。
4. 可复现性。环境和半径均采用确定性的 PCHIP，数值程序无随机过程；论文表格与
  数据图来自同一终算文件，并通过网格、步长、方程平衡和长期二维多重检查。
5. 输出完整性。固定域解与固定物理位置输出被明确区分，落到收缩药材外部的列按
  几何规则留空，真实首达时间也不被 60 s 输出间隔量化。


10 . 5 模型局限

   首先，热湿耦合只通过题给物性函数体现，没有显式描述水分蒸发消耗的潜热。若
真实蒸发冷却显著，本文可能高估材料升温速度并进一步高估 D(T, C)。但在缺少潜热、
平衡吸湿关系和相变边界数据时，加入该项需要额外参数，不能由现有附件唯一确定。
   其次，主模型代表中截面而非端面。长期二维核验在当前端面条件下确认轴线与中
截面交点控制达标；若长度、端部交换条件或各向异性改变，仍需重新核验全域控制点。
再次，材料被视为均匀各向同性；实际药材的纤维方向、表皮和内部空腔可能使径向与
轴向扩散系数不同。
   最后，4 h 后环境采用常值延拓，虽然灵敏度分析表明结论对小幅扰动稳定，但它仍
是长期预测的主要外部不确定性来源。问题四又假设收缩为均匀材料径向缩放，并区分
守恒干骨架密度与题给有效热物性；这些闭合尚未经实验辨识，也没有考虑局部开裂、

                                            32
翘曲和长度变化。本文结果因此更适合作为给定附件条件下的理论预测和控制基线，而
非未经标定即可替代实际烘干试验。


10 . 6 工程应用与模型推广

     从控制角度看，表面温度和表面水分都过早接近环境或阈值，不能单独作为停机信
号。可在少量试验中布置中心温湿传感器，用本文模型反演或校正 D, hm ，随后建立由
环境历史和表面观测预测中心水分的降阶代理模型。控制器以预测中心水分首次达到
0.15 为停机条件，可兼顾内部达标与表层不过度干燥。
     根据问题一至三的阶段特征，还可构造两阶段温度策略：早期在允许的品质温度范
围内提高环境温度，利用较高 D 加快内部扩散；后期中心接近阈值时降低温度或采用
间歇均湿，使内外水分重新分配。具体最优温度轨迹需要增加品质损失、能耗和设备上
下限等目标与约束，本文框架可直接作为最优控制中的状态方程。
     若获得蒸发潜热、平衡含湿曲线和交叉输运系数，可将 (3) 和 (4) 推广为 Luikov 型
热湿耦合方程 [4]；若药材长度较短或端面换热强化，则采用本文二维核验模型；若收缩
出现各向异性，则把单一 R(t) 扩展为轴向、径向两个尺度函数。因而，该方法不仅适用
于中药材，也可用于果蔬、食品、木材及其他多孔生物材料的变物性干燥和收缩预测。

def face_interpolate(left: np.ndarray, right: np.ndarray) -> np.ndarray:
    """Linear face interpolation for a smooth state-dependent coefficient."""
    return 0.5 * (left + right)



def radial_grid(count: int, radius: float = 1.0) -> np.ndarray:
    """Surface-refined computational mesh; output positions are independent."""
    s = np.linspace(0.0, 1.0, count)
    return radius * (1.0 - (1.0 - s) ** GRID_POWER)



def node_control_volumes(coordinate: np.ndarray) -> tuple[np.ndarray, np.ndarray]:
    """Return dimensionless/physical radial CV volumes and internal face radii."""
    faces = 0.5 * (coordinate[:-1] + coordinate[1:])
    lower = np.concatenate(([0.0], faces))
    upper = np.concatenate((faces, [coordinate[-1]]))
    volumes = math.pi * (upper**2 - lower**2)
    return volumes, faces



def implicit_radial_step(
    old: np.ndarray,
    storage: np.ndarray,
    conductivity: np.ndarray,
    dt: float,
    coordinate: np.ndarray,
    diffusion_scale: float,


                                                39
    boundary_conductance: float,
    boundary_value: float,
    advection_velocity: np.ndarray | None = None,
) -> np.ndarray:
    """One implicit node-centred radial FVM step on coordinate [0, 1] or [0, R]."""
    count = len(old)
    volumes, faces = node_control_volumes(coordinate)
    delta = np.diff(coordinate)
    face_property = face_interpolate(conductivity[:-1], conductivity[1:])
    conductance = 2.0 * math.pi * faces * face_property * diffusion_scale / delta


    capacity = storage * volumes / dt
    diagonal = capacity.copy()
    lower = np.zeros(count - 1)
    upper = np.zeros(count - 1)
    rhs = capacity * old


    diagonal[:-1] += conductance
    diagonal[1:] += conductance
    upper -= conductance
    lower -= conductance


    diagonal[-1] += boundary_conductance
    rhs[-1] += boundary_conductance * boundary_value


    if advection_velocity is not None:
        # PDE form: phi_t + u(xi) phi_xi = diffusion; u >= 0 under shrinkage.
        advective = storage[1:] * volumes[1:] * np.maximum(advection_velocity[1:], 0.0) / delta
        diagonal[1:] += advective
        lower -= advective


    matrix = np.zeros((3, count))
    matrix[0, 1:] = upper
    matrix[1, :] = diagonal
    matrix[2, :-1] = lower
    return solve_banded((1, 1), matrix, rhs, check_finite=False)



def advance_coupled(
    temperature_old: np.ndarray,
    moisture_old: np.ndarray,
    dt: float,
    radius_m: float,
    radius_rate_m_s: float,
    ambient_temperature_c: float,
    ambient_moisture: float,
    property_model: Callable[[np.ndarray, np.ndarray], tuple[np.ndarray, ...]],


                                              40
   moving_domain: bool,
   tolerance_temperature: float = 1e-8,
   tolerance_moisture: float = 1e-10,
   max_iterations: int = 30,
   balance: dict | None = None,
) -> tuple[np.ndarray, np.ndarray, int]:
   temperature = temperature_old.copy()
   moisture = moisture_old.copy()
   if moving_domain:
       coordinate = radial_grid(len(temperature_old))
       diffusion_scale = 1.0 / radius_m**2
       boundary_scale = 1.0 / radius_m
       shrink_velocity = -(radius_rate_m_s / radius_m) * coordinate
   else:
       coordinate = radial_grid(len(temperature_old), radius_m)
       diffusion_scale = 1.0
       boundary_scale = 1.0
       shrink_velocity = None


   for iteration in range(1, max_iterations + 1):
       rho, cp, k, _ = property_model(temperature, moisture)
       heat_storage = rho * cp
       heat_boundary = 2.0 * math.pi * coordinate[-1] * H_T * boundary_scale
       next_temperature = implicit_radial_step(
            old=temperature_old,
            storage=heat_storage,
            conductivity=k,
            dt=dt,
            coordinate=coordinate,
            diffusion_scale=diffusion_scale,
            boundary_conductance=heat_boundary,
            boundary_value=ambient_temperature_c,
            advection_velocity=shrink_velocity,
       )


       _, _, _, diffusivity = property_model(next_temperature, moisture)
       mass_boundary = 2.0 * math.pi * coordinate[-1] * H_M * boundary_scale
       next_moisture = implicit_radial_step(
            old=moisture_old,
            storage=np.ones_like(moisture),
            conductivity=diffusivity,
            dt=dt,
            coordinate=coordinate,
            diffusion_scale=diffusion_scale,
            boundary_conductance=mass_boundary,
            boundary_value=ambient_moisture,
            advection_velocity=shrink_velocity,


                                               41
       )


       error_t = float(np.max(np.abs(next_temperature - temperature)))
       error_c = float(np.max(np.abs(next_moisture - moisture)))
       temperature = next_temperature
       moisture = next_moisture
       if error_t < tolerance_temperature and error_c < tolerance_moisture:
            break
   else:
       raise RuntimeError(
            f"Picard iteration failed: dT={error_t:.3e}, dC={error_c:.3e}, dt={dt}"
       )


   if not np.all(np.isfinite(temperature)) or not np.all(np.isfinite(moisture)):
       raise FloatingPointError("Non-finite state generated.")
   if np.min(moisture) < -1e-10 or np.max(moisture) > INITIAL_C + 1e-8:
       raise FloatingPointError("Moisture left physical bounds.")
   if balance is not None:
       volumes, _ = node_control_volumes(coordinate)
       adv_c = adv_t = 0.0
       if shrink_velocity is not None:
            weight = volumes[1:] * np.maximum(shrink_velocity[1:], 0.0) / np.diff(coordinate)
            adv_c = dt * float(np.dot(weight, np.diff(moisture)))
            adv_t = dt * float(np.dot(weight * heat_storage[1:], np.diff(temperature)))
       change = float(np.dot(volumes, moisture - moisture_old))
       flux = dt * mass_boundary * (float(moisture[-1]) - ambient_moisture)
       reference = INITIAL_C * float(volumes.sum())
       balance['moisture_change'] += change / reference
       balance['boundary_loss'] += flux / reference
       balance['relative_transport'] += adv_c / reference
       residual = change + flux + adv_c
       balance['maximum_step_mass_residual'] = max(balance['maximum_step_mass_residual'],
    abs(residual) / reference)
       heat_change = float(np.dot(heat_storage * volumes, temperature - temperature_old))
       heat_flux = dt * heat_boundary * (float(temperature[-1]) - ambient_temperature_c)
       heat_reference = INITIAL_T * float(np.dot(heat_storage, volumes))
       heat_residual = (heat_change + heat_flux + adv_t) / heat_reference
       balance['maximum_step_heat_equation_residual'] =
    max(balance['maximum_step_heat_equation_residual'], abs(heat_residual))
   return temperature, moisture, iteration



def new_balance() -> dict:
   return dict(moisture_change=0.0, boundary_loss=0.0, relative_transport=0.0,
                maximum_step_mass_residual=0.0, maximum_step_heat_equation_residual=0.0)

def extract_fixed_table(
    simulation: dict[str, np.ndarray | float | int | bool],
    requested_times_s: list[float],
    requested_radii_cm: list[float],
    variable: str,
) -> list[list[float]]:
    times = np.asarray(simulation["times_s"])
    radii_m = np.asarray(simulation["radius_m"])
    values = np.asarray(simulation[variable])
    table: list[list[float]] = []
    for requested_time in requested_times_s:
        threshold_time = float(simulation.get("threshold_time_s", math.nan))
        threshold_key = (
               "threshold_temperature_c" if variable == "temperature_c" else "threshold_moisture"
        )


                                                  47
         threshold_profile = simulation.get(threshold_key)
         if (
                threshold_profile is not None
                and math.isfinite(threshold_time)
                and abs(requested_time - threshold_time) < 1e-5
         ):
                profile = np.asarray(threshold_profile)
         else:
                time_index = int(np.argmin(np.abs(times - requested_time)))
                profile = values[time_index]
         row = [
                float(np.interp(radius_cm / 100.0, radii_m, profile))
                for radius_cm in requested_radii_cm
         ]
         table.append(row)
    return table

def json_ready(value):
    if isinstance(value, np.ndarray):
        return value.tolist()
    if isinstance(value, (np.floating, np.integer)):
        return value.item()
    if isinstance(value, float) and math.isnan(value):
        return None
    if isinstance(value, dict):
        return {key: json_ready(item) for key, item in value.items()}
    if isinstance(value, (list, tuple)):
        return [json_ready(item) for item in value]
    return value



def write_summary(path: Path, payload: dict) -> None:
    path.write_text(
        json.dumps(json_ready(payload), ensure_ascii=False, indent=2),
        encoding="utf-8",
    )

基于变物性与收缩效应的圆柱药材热湿迁移模型
摘要
针对圆柱形药材烘干中环境边界时变、内部温湿分布不均、物性非线性及几何收缩
相互影响的问题，本文构建统一的变物性径向热湿有限体积框架。以PCHIP 重构附件
中的环境量和半径曲线，以Fourier–Fick 方程描述内部传递，采用节点中心有限体积法
与全隐式格式保证离散守恒和长时计算稳定，并通过Picard 迭代处理状态相关物性；进
一步以材料坐标下的固定域映射描述收缩边界，以全截面首达时间统一衡量干燥终点。
针对问题一：在固定半径和给定物性下，建立Fourier–Fick 基准模型，将时变环境
量作为双Robin 边界输入并逐秒求解。利用中心圆盘控制体处理轴线边界，结合表面加
密网格解析外层梯度。1800 s 时中心与表面温度分别为33.577 ◦C 和36.786 ◦C，水分
浓度分别为2.550 和1.510 kg/kg。结果表明预热初期水分主要从表层逸出，内部水分
浓度仍接近初值。
针对问题二：在基准模型上引入ρ(C), cp(C), k(C) 与D(T, C)，构造温度–水分状态
耦合的非线性扩散模型，每个时间层交替更新温度、扩散系数和水分场，以双重收敛判
据保证物性与场量自洽，刻画升温促进扩散与失水抑制扩散的竞争。3 h 时中心与表面
温度达到49.849 ◦C 和49.967 ◦C，水分浓度降至1.766 和1.008 kg/kg。此时径向温差
已很小，而水分梯度仍然明显，后续过程主要受内部传质控制。
针对问题三：将问题二模型延伸至长期干燥，以maxr C(r, t) ≤0.15 kg/kg 定义全
截面达标，并对跨越阈值的相邻时间层实施线性事件插值。通过径向单调性与含端面传
递的二维计算核验控制位置，区分输出间隔与事件定位精度。根据末段观测的稳定水
平，假设4 h 后环境保持为Te = 50 ◦C、Ce = 0.05 kg/kg。全域首达检测得到干燥时间
为57.472 h，达标瞬间中心和表面水分浓度分别为0.150 和0.053 kg/kg。全程中心均
为最大值，说明仅依据表面含水率停机将低估内部干燥时间。
针对问题四：建立收缩移动边界热湿耦合模型，通过ξ = r/R(t) 将时变物理区域映
射到固定计算域；同时将半径收缩引起的扩散距离缩短及表面交换变化纳入模型。在均
匀材料收缩与干骨架守恒假设下，使材料速度与网格速度一致，并以同物性对照分离几
何贡献。移动边界模型得到干燥时间为51.088 h，达标半径为1.200 cm；同物性固定
半径方案需129.845 h，收缩使时长缩短60.7%。进一步采用移动网格验证，两种坐标实
现的结果在浮点舍入量级内一致；COMSOL 有限元复核经表层网格加密后，最大水分
差降至4.54 × 10−5 kg/kg，支持既定模型的数值可靠性。
数值收敛、长期二维核验及移动网格交叉验证表明模型结果具有良好的稳定性与可
靠性。灵敏度分析显示，环境温度是影响干燥时长的主要外部因素，所建模型可用于描
述变物性与收缩条件下圆柱药材的热湿迁移过程。

一、问题重述
1 . 1 问题背景
药材烘干过程同时包含内部传热和水分迁移。外部温度变化首先作用于药材表面，
热量向内部传递；水分则在浓度梯度和表面传质作用下由内部向外迁移。由于热扩散和
水分扩散的时间尺度不同，温度场和水分场通常具有明显的径向非均匀性，表面状态不
能代表整个截面的状态。因此，需要建立描述药材内部温度和水分浓度时空分布的非稳
态模型，并以全截面状态作为干燥完成的判断依据。
本题研究一根长25 cm、初始半径2 cm 的近似圆柱形药材，初始温度和水分浓度分
别为28 ◦C 和2.55 kg/kg。已知条件依次引入时变环境、状态相关物性、全截面含水率
约束以及半径收缩。因而四个问题分别对应恒定热物性、变物性耦合、全域达标判定和
移动边界四个层次；其中问题一仍保留水分扩散系数D(C) 的非线性，模型在统一热湿
传递框架下逐步增加相应的物理因素。
1 . 2 问题提出
根据题目给定的几何尺寸、初始状态、环境条件及物性关系，本文需要获得药材内
部温度和水分浓度的时空分布，并确定全截面达到含水率要求的时间。四问的区别在于
逐步增加物性变化、全域约束和几何收缩等因素，因此采用由简到繁的统一建模路线。
问题一：首先需要刻画预热阶段药材内部热量与水分的径向迁移规律。由于药材内
部存在明显的温度和水分梯度，应建立圆柱坐标下的非稳态传热传质模型，并结合时变
环境边界求得温湿场，为后续各问提供统一的基础模型和数值求解框架。
问题二：在基础模型上进一步考虑物性随温度和水分状态变化的影响，使导热、储
热和水分扩散过程相互耦合。由此需将问题一的基准模型扩展为变物性的非线性热湿迁
移模型，以分析整个烘干过程中温度场与水分场的动态演化及其控制机制。
问题三：在获得长期水分迁移规律后，需要进一步解决“何时完成烘干”的判定问
题。将“药材各处水分均低于规定阈值”转化为空间最大水分浓度的首达条件，并据此
确定控制位置及最终烘干时间，从而避免仅依据表面或平均水分作出过早停机判断。
问题四：实际烘干过程中药材半径持续收缩，使计算区域由固定域转化为移动域。
为此需在变物性热湿模型中进一步引入时变几何边界，通过固定域映射处理收缩过程，
并分析扩散距离缩短对烘干效率的影响；同时采用独立移动网格计算以及COMSOL 物
理仿真对移动边界结果进行交叉验证。

2 . 1 问题一的分析
问题一的半径和主要热物性给定为常数，但热量和水分仍需在药材内部传递。热、
质扩散特征时间不同，且表面对流边界不能忽略，因此不能用截面平均量描述预热过
程。本文建立一维径向热湿传递模型，保留水分扩散系数D(C) 的非线性；由附件重构
时变环境，在中心和表面分别设置对称与Robin 边界，并采用有限体积法求解预热阶段
的温湿分布，为后续各问提供统一的离散框架。
2 . 2 问题二的分析
问题一的恒定热物性假设不能反映干燥过程中密度、比热和导热系数随状态变化
的影响，水分扩散系数则已保留D(C) 的非线性。问题二进一步引入状态相关热物性及
D(T, C)，形成温度场与水分场相互影响的非线性耦合模型。由于系数依赖待求状态，采
用分步Picard 迭代更新温度、水分与物性，获得同一时间层的自洽解，再比较中心与表
面的响应。
2 . 3 问题三的分析
问题三要求所有位置的水分浓度均不超过0.15 kg/kg，因此表面浓度或截面平均浓
度都不能作为停机依据。本文在问题二模型上延长计算时间，以全域最大水分浓度的首
3
次达标作为事件判据；通过全过程剖面检查确定控制位置，并在阈值附近进行时间插值，
以提高达标时间的定位精度。
2 . 4 问题四的分析
问题四中药材半径随时间变化，固定空间区域和固定网格不能直接描述材料边界的
移动。本文假设药材均匀径向收缩，利用ξ = r/R(t) 将移动域映射至固定区间，并在问
题二的变物性热湿模型上更新几何尺度。为区分收缩本身的影响，另设使用相同物性和
环境的固定半径对照模型；再用物理坐标移动网格与COMSOL 有限元计算进行交叉验
证。
三、模型假设
依据题给几何、物性和边界数据，采用以下等效化与闭合假设；其依据及检验范围
在相应模型中说明。
1. 介质与几何。用题给标量物性表征均匀、各向同性的等效连续介质，初始温湿场均
匀且轴对称。主模型保留中截面径向梯度；圆柱几何为降维提供依据，端面影响由
后文二维对照检验。
2. 传递机制。以导热和Fick 扩散描述内部热湿迁移，耦合通过题给状态相关物性体现。
不另设内热源、辐射、内部宏观对流、重力渗流及托盘接触传热通道，以题给物性
对应的扩散过程为研究范围。
3. 表面交换与浓度口径。表面采用Robin 边界；问题一取题给的hT = 25 W/(m2K)、
hm = 8 × 10−7 m/s，后续三问假设沿用。将附件环境水分量的数值作为与药材干基
含水率可比较的等效边界值Ce，这一映射由传质边界的闭合假设确定。
4. 蒸发潜热。采用基于题给热物性的导热方程，不单列蒸发潜热项，也不将其视为已
包含在ρcp 中。蒸发冷却对温度和达标时长的影响尚未量化，相关结果解释为这一
热过程简化下的条件预测。
5. 环境延拓。附件一末段观测接近稳定水平，故假设14400 s 后Te = 50.000 ◦C、Ce =
0.05000 kg/kg。该设定代表后续工况保持不变的情景，合理性由末段统计与环境扰
动分析共同评估。
6. 收缩闭合。问题四保持长度不变，材料点沿径向同比例收缩；无干物质流失，且干
骨架密度在截面内均匀，满足ρdR2 = ρd0R2

十、模型的评价与推广
10 . 1 模型的评价
模型的优点：
1. 四问采用统一的热湿迁移框架，依次引入状态相关物性、全域首达判据与材料收缩，
能够衔接短期预热和长期干燥预测。
2. 有限体积法直接平衡控制体通量，全隐式与Picard 迭代适应非线性物性；网格、步
长、二维及交叉求解检验支持数值结果的可靠性。
3. 全域阈值判据识别中心控制位置，同物性固定半径对照分离几何收缩效应，便于解
释干燥时间差异。
模型的局限：
1. 中截面近似获得同物性、同边界二维对照的支持，但材料各向异性及蒸发潜热的影
响尚未量化；既有数值验证不能替代对这些物理简化的检验。
2. 环境水分采用等效映射，交换系数沿用题给值，长期边界取常值延拓；实际应用需
标定浓度转换与表面交换关系，并将后续工况变化纳入预测范围。
3. 收缩模型以给定半径历史和均匀径向缩放闭合内部运动。水分守恒和坐标实现对照
支持这一闭合的数值自洽性，实际局部变形、长度变化及完整能量平衡仍需另行验
证。
10 . 2 模型的推广
结合少量中心温湿测量，可标定扩散与表面交换参数，利用模型估计内部达标时刻，
并进一步加入能耗、品质和设备约束以优化干燥温度策略。
对短柱或端面交换显著的材料，可采用二维轴对称模型；获得潜热和吸湿数据后，
可扩展为Luikov 型热湿耦合模型[4]。经物性与边界重新标定，该框架可用于果蔬、木
材等多孔材料的干燥预测。

def face_interpolate(left: np.ndarray, right: np.ndarray) -> np.ndarray:
"""Linear face interpolation for a smooth state-dependent coefficient."""
return 0.5 * (left + right)
def radial_grid(count: int, radius: float = 1.0) -> np.ndarray:
"""Surface-refined computational mesh; output positions are independent."""
s = np.linspace(0.0, 1.0, count)
return radius * (1.0 - (1.0 - s) ** GRID_POWER)
def node_control_volumes(coordinate: np.ndarray) -> tuple[np.ndarray, np.ndarray]:
"""Return dimensionless/physical radial CV volumes and internal face radii."""
faces = 0.5 * (coordinate[:-1] + coordinate[1:])
lower = np.concatenate(([0.0], faces))
upper = np.concatenate((faces, [coordinate[-1]]))
volumes = math.pi * (upper**2 - lower**2)
return volumes, faces
def implicit_radial_step(
old: np.ndarray,
storage: np.ndarray,
conductivity: np.ndarray,
dt: float,
coordinate: np.ndarray,
diffusion_scale: float,
38
boundary_conductance: float,
boundary_value: float,
advection_velocity: np.ndarray | None = None,
) -> np.ndarray:
"""One implicit node-centred radial FVM step on coordinate [0, 1] or [0, R]."""
count = len(old)
volumes, faces = node_control_volumes(coordinate)
delta = np.diff(coordinate)
face_property = face_interpolate(conductivity[:-1], conductivity[1:])
conductance = 2.0 * math.pi * faces * face_property * diffusion_scale / delta
capacity = storage * volumes / dt
diagonal = capacity.copy()
lower = np.zeros(count - 1)
upper = np.zeros(count - 1)
rhs = capacity * old
diagonal[:-1] += conductance
diagonal[1:] += conductance
upper -= conductance
lower -= conductance
diagonal[-1] += boundary_conductance
rhs[-1] += boundary_conductance * boundary_value
if advection_velocity is not None:
# PDE form: phi_t + u(xi) phi_xi = diffusion; u >= 0 under shrinkage.
advective = storage[1:] * volumes[1:] * np.maximum(advection_velocity[1:], 0.0) / delta
diagonal[1:] += advective
lower -= advective
matrix = np.zeros((3, count))
matrix[0, 1:] = upper
matrix[1, :] = diagonal
matrix[2, :-1] = lower
return solve_banded((1, 1), matrix, rhs, check_finite=False)

next_moisture = implicit_radial_step(
old=moisture_old,
storage=np.ones_like(moisture),
conductivity=diffusivity,
dt=dt,
coordinate=coordinate,
diffusion_scale=diffusion_scale,
boundary_conductance=mass_boundary,
boundary_value=ambient_moisture,
advection_velocity=shrink_velocity,

)

error_c = float(np.max(np.abs(next_moisture - moisture)))

moisture = next_moisture

adv_t = dt * float(np.dot(weight * heat_storage[1:], np.diff(temperature)))

reference = INITIAL_C * float(volumes.sum())
balance['moisture_change'] += change / reference
balance['boundary_loss'] += flux / reference
balance['relative_transport'] += adv_c / reference
residual = change + flux + adv_c
balance['maximum_step_mass_residual'] = max(balance['maximum_step_mass_residual'],
abs(residual) / reference)
heat_change = float(np.dot(heat_storage * volumes, temperature - temperature_old))
heat_flux = dt * heat_boundary * (float(temperature[-1]) - ambient_temperature_c)
heat_reference = INITIAL_T * float(np.dot(heat_storage, volumes))
heat_residual = (heat_change + heat_flux + adv_t) / heat_reference
balance['maximum_step_heat_equation_residual'] =
max(balance['maximum_step_heat_equation_residual'], abs(heat_residual))
return temperature, moisture, iteration

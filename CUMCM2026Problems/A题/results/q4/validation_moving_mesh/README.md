## 复现

在 A题目录运行。日常核验已有结果及最新论文，先编译 `paper/cumcm-1.1.0/main.tex` 并保留本次编译日志，再执行：

```powershell
python code/check_moving_mesh_delivery.py --log paper/cumcm-1.1.0/build/main.log
```

日志在其他位置时，通过 `--log` 指定实际路径；报告默认写入本目录 `delivery_checks.json`，也可用 `--report` 指定另一份 JSON。脚本检查当前时间轴、场、首达事件、正式结果重现误差和编译日志，并记录本次检查前后的文件指纹。它不积分、不生成图表，也不复制提交 PDF；只有显式添加 `--package` 才复制 `main.pdf` 为 `A题_完整论文.pdf`。使用 `--skip-build-check` 时只检查数据和 PDF，报告明确标为“编译未验证”，不能作为编译通过的记录。

如果需要重新生成独立积分结果，计算入口为 `python code/validate_moving_mesh.py`；只检查基础物理性质可加 `--check-only`。绘图入口为 `python code/plot_moving_mesh_validation.py`，它保留生成时的保护清单核验。计算、绘图会写入相应结果，不能代替上述对已有成果的验收。绘图后需重新编译论文，直到交叉引用稳定，再使用本次日志运行验收。

## 文件

- `summary.json`：首达时刻、全程全节点最大差、Picard 次数、守恒残差。
- `comparison.csv` / `comparison_table_zh.md`：6、24、48 h 与达标时刻的中心/动态表面比较；相对差为绝对差除以固定域值，不是百分数。
- `profiles.csv`：6、24、48 h 及各自首达时刻完整 161 节点物理半径、水分、温度剖面。`own_event` 指各自达标时刻；`comparison.csv` 的 `common_event` 则在固定域首达时刻对两条逐秒轨迹独立插值，避免用两个恰为 0.15 的事件值代替同刻比较。
- `fields.npz`：逐分钟完整场和逐秒轨迹。`xi` 为 161 个节点标签；`times_s`、`radii_m` 为分钟帧坐标；`mapping_*` / `moving_*` 为两套场；`*_event_*` 为各自事件插值场。
- `step_trace` 列依次为：时间秒、固定域中心C、移动网格中心C、固定域表面C、移动网格表面C、全节点最大水分差、全节点最大温度差、中心水分绝对差。误差最大值由全部 183961 个时间层计算；当前数组尺寸为 `(183961, 8)`，分钟场尺寸为 `(3067, 161)`。
- `q4_moving_mesh_validation.pdf/png`：中心轨迹及24/48 h剖面；`q4_moving_mesh_errors.pdf/png`：逐秒全场差异，非统计不确定度。
- `unit_checks.json`：几何守恒、绝热绝湿收缩常值、静止网格退化检查。
- `reference_reproduction.json`：重算固定域结果与原结果的水分、温度、干燥时间差均为0。
- `protected_files_sha256.json`：生成独立验证时保存的历史保护清单，最近记录该清单的提交为 `566a7614dc16ff9815c87470f08345ddccb23956`。保留原文件用于溯源，不能要求后续修订仍与其中全部旧哈希一致，也不能重写旧哈希来表示当前验收通过。

## 数值结果与理论边界

按当前 `summary.json`，固定域 t_d=51.08769929956615 h，移动网格 t_d=51.08769929959585 h；绝对差1.0692747309803963e-7 s，相对差5.813938828288319e-13。中心轨迹最大水分差8.659739592076221e-14 kg/kg，全场最大水分差2.6145752229922437e-13 kg/kg，温度最大差1.1645795439108042e-10 ℃。这些差值是两套离散实现之间的差，不是连续方程精确解误差，也不代表物理预测有这些有效位数。

采用材料速度等于网格速度的 ALE 闭合，运动对流通量因相对速度为零而消失；用干质量库存与物理面积/间距直接组装通量，同时核验几何扫掠守恒。热方程沿用有效 a D_t T 方程，其库存形式必须保留 T_old Δ(aV) 修正，不能宣称总焓无源守恒。详细推导见 [离散原理](../../../reports/Q4_MOVING_MESH_PRINCIPLE.md)。

在这些既有假设下，两套离散可代数互相对应，因此浮点量级的差异合理。这是独立几何/矩阵组装的数值互证，不是第二种物理机制或实验验证。一般 ALE 守恒与几何守恒原则参考 [Gaburro 等的原始论文](https://arxiv.org/abs/1602.01703)，本题一维离散由项目自行推导并检查。

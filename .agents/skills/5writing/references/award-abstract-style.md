# 全国大学生数学建模竞赛高水平摘要规范

## 适用范围

本规范用于生成或润色全国大学生数学建模竞赛中文论文摘要。摘要不是正文压缩版，而是供评委快速扫读的独立成果页：先说明问题本质与统一框架，再呈现各问最关键的方法和量化结果，最后交代可信度证据与可推广场景。

## 总体目标

- 正文原则上控制在 600--850 个中文字；含 4--5 个子问题时可放宽至约 900 字，但不得用次要参数凑篇幅。
- 逻辑链固定为“问题核心 -> 统一建模框架或创新 -> 各问方法与结果 -> 可靠性验证 -> 模型价值”。
- 每问原则上仅保留研究对象、最关键的方法或模型、最重要的 1--2 个结果。
- 优先解释为何如此建模、解决了什么关键困难，其次再交代算法名称。
- 不搬运公式、完整决策变量、坐标、算法参数、迭代次数或逐项方案表，除非它们本身就是题目要求的核心答案。
- 禁止“建立模型进行求解”“运用相关知识”“取得较好结果”“模型具有一定合理性”等无信息量表述；必须写明模型对象、约束或困难以及量化结论。

## 固定分段结构

摘要正文按“总述段 + 每问独立段 + 验证推广段”组织，不设小标题。每个子问题必须独占一个自然段，并依次以加粗的“针对问题一：”至“针对问题五：”开头；五问论文因此固定为 7 个自然段。

### 第一段：问题核心、总体模型与核心创新

建议 120--180 字。本段必须回答：本质优化目标是什么、全文采用什么统一模型框架、相较常见简单处理最重要的改进是什么。可使用“针对……问题，本文构建……模型”“不同于仅采用……的处理方式，本文……”“通过……刻画……，并将……统一转化为……问题”等句式。

本段不大量报告最终结果，最多出现 1 个关键物理阈值或模型参数。若正文确有依据，优先呈现更真实的几何建模、非点目标、时空耦合、多目标资源分配、区间并集、鲁棒优化、混合整数与连续优化、事件检测或求根、分层优化等真正有区分度的创新。

### 中间各段：每问独立陈述

每个子问题建议 75--125 字，必须独占一个自然段，并以加粗的“针对问题 X：”作为段首。每问使用 1--2 句：一句交代新增困难、模型或求解思想，一句给出核心结果。相邻问题通过“在此基础上”“进一步加入”“由单平台扩展至多平台”等内容关系体现递进，不再依靠把多问挤入同一段落来衔接。

- 问题一：基准模型、基础计算结果，以及必要的敏感性或口径验证。
- 问题二：新增决策变量、优化思想及最优候选目标值；启发式方法不得无依据声称全局最优。
- 问题三：新增耦合约束、多个结果的合并口径及联合效果。

不要罗列每枚资源的坐标、每个投放时刻或所有决策变量数值。

- 问题四：说明单平台优化如何扩展为多平台协同、不同平台为何形成时间或空间互补，并报告联合目标值。
- 问题五：说明离散任务分配与连续参数优化如何耦合、如何降低高维搜索复杂度，以及最终资源规模和各目标或总目标。结果较多时使用“最终使用 X 个资源，使三个目标分别达到 A、B、C，总目标为 D”，不要展开冗长的平台与目标对应表。

### 末段：验证、稳健性与模型价值

建议 90--150 字，不重复前三段结果。从数值收敛、网格加密、事件求根、灵敏度分析、可行性回代、约束检验、多随机种子复核和鲁棒性验证中选最重要的 2--3 项。末句必须明确框架可推广到何种问题，例如含时空窗口、平台容量和资源分配约束的覆盖或调度问题；不得只写“模型具有良好的推广性”。

## 强调格式

- 若输出支持 Markdown，使用 `**加粗**`；若写入 LaTeX，使用 `\textbf{...}`。
- 全文只允许 5--9 处加粗，且加粗内容不超过摘要正文的 15%；五个“针对问题 X：”标签计入该总数。
- 在五问论文中，先保证五个问题标签加粗，再从核心模型或创新、关键方法和最重要的最终结果中选择其余 0--4 处强调。
- 禁止逐个数字加粗、整句或整段加粗；不得在五个问题标签之外重复加粗问题名称。
- 加粗应使评委在 5--10 秒内识别“核心模型是什么、关键结果是什么”。

## 数值与语言

- 一般数值默认保留 3 位小数，百分比保留 1 位；同类数值精度必须一致。
- 除题目明确要求高精度或用于说明收敛外，不在摘要保留 6 位小数。高精度结果留在正文和表格。
- 使用正式、克制、信息密度高的中文科技论文语言，优先使用“构建、刻画、引入、转化为、以……为目标、采用……求解、结果表明、最终得到”。
- 减少流水账式的“首先、然后、接着、最后”，禁止“完美解决”“显著优于所有方法”等夸张结论。
- 对差分进化、粒子群等启发式算法，写“获得最优候选解”或“得到当前搜索范围内的最优方案”；除非有严格证明，不得写“得到全局最优解”。

## 关键词

- 关键词控制为 4--6 个，按“研究对象、核心几何或数学模型、主要优化方法、协同或任务分配方法”选择，并保持同一层级。
- 不使用“数学模型、优化、算法、计算机仿真”等过泛词。
- Markdown 可仅加粗“关键词：”；LaTeX 使用模板的 `\keywords{关键词一\quad 关键词二...}`，不逐个加粗关键词。

## 输出前的内部提取

输出前在内部完成以下工作，不展示分析过程：

1. 提取题目的核心矛盾与全文统一模型。
2. 找出 1--3 个真正有区分度的创新点。
3. 对每个子问题提取新增约束、新增模型、求解方法和最终核心结果。
4. 找出数值精度、敏感性或鲁棒性证据，并删除次要参数。
5. 先将各问“针对问题 X：”标签纳入加粗项，再在总计 5--9 处的限额内选择最值得强调的模型、方法或结果，最后按“总述段 + 每问独立段 + 验证推广段”生成摘要。

## 强制自检

生成后逐项检查；任一关键项不满足时自动重写，不直接交付：

- 第一段是否出现全文核心模型？
- 是否按“总述段 + 每问独立段 + 验证推广段”组织，五问时恰为 7 个自然段？
- 是否每个子问题均独占一个自然段，并以加粗的“针对问题 X：”作为段首？
- 每个子问题是否至少出现方法或结果之一？
- 是否避免把正文参数列表搬入摘要？
- 关键数值是否精简且统一为合适精度？
- 是否区分模型创新与算法名称？
- 是否给出结果可信性证据？
- 末句是否说明具体适用问题？
- 是否约 600--850 字，五问时不超过约 900 字？
- 是否仅有 5--9 处加粗且不超过正文 15%？
- 关键词是否为 4--6 个？
